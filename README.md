# สมุดรายรับ–รายจ่าย (Money Book)

เว็บแอปบันทึกรายรับรายจ่ายภาษาไทย ที่ **คิดเลขในช่องจำนวนเงินได้เลย** ติดตั้งลงมือถือหรือคอมได้เหมือนแอปทั่วไป และใช้งานได้แม้ไม่มีเน็ต

**เปิดใช้งาน →** https://yuttachaicp-ops.github.io/money-book/

---

## ความสามารถ

| หัวข้อ | รายละเอียด |
|---|---|
| คิดเลขในตัว | พิมพ์สูตรลงช่องจำนวนเงินได้ตรง ๆ — `85*3+120` = 375, `(1200+300)/2` = 750, `1200*7%` = 84 พร้อมแสดงผลลัพธ์ก่อนกดบันทึก |
| ปุ่ม VAT | `+ VAT 7%` คูณ 1.07 และ `ถอด VAT` หาร 1.07 ให้อัตโนมัติ |
| ตารางแบบสมุดบัญชี | คอลัมน์ วันที่ / รายการ / หมวดหมู่ / รายรับ / รายจ่าย / คงเหลือสะสม |
| สรุปยอด | รายรับ รายจ่าย และคงเหลือของเดือนที่เลือก |
| กราฟแนวโน้มรายเดือน | แท่งคู่รายรับ/รายจ่ายย้อนหลัง 12 เดือน พร้อมยอดคงเหลือใต้ชื่อเดือน |
| กราฟสัดส่วนหมวดหมู่ | วงโดนัทสลับดูรายรับ/รายจ่ายได้ พร้อมรายการเรียงลำดับและเปอร์เซ็นต์ |
| งบต่อหมวด | ตั้งงบรายเดือนต่อหมวด มีเส้นบอกจังหวะของเดือน บอกว่าใช้เร็วกว่าจังหวะหรือยัง และเตือนตอนบันทึกรายการที่ทำให้เกินงบ |
| ตั้งงบอัตโนมัติ | ปุ่มเดียวคำนวณงบจากค่าใช้จ่ายจริง 3 เดือนที่ผ่านมา แล้วแก้ตัวเลขเองได้ |
| เป้ารายรับ / เพดานรายจ่าย | ตั้งเป้ายอดขายและเพดานรายจ่ายรวมต่อเดือน |
| เป้าเก็บเงิน | ตั้งยอดกับเดือนที่อยากได้ แอปบอกว่าต้องเก็บเดือนละเท่าไหร่ถึงจะทัน |
| จดยอดหนี้ | แยกสองฝั่ง — หนี้ที่เราติดเขา (ผ่อนรถ บัตรเครดิต ค้างซัพพลายเออร์) และลูกหนี้ที่ติดเรา (ลูกค้าซื้อเชื่อ เพื่อนยืม) |
| เตือนครบกำหนด | บอกว่าอีกกี่วันครบกำหนด หรือเกินกำหนดมากี่วัน เรียงรายการที่เกินกำหนดขึ้นก่อน และมีจุดแดงบนแท็บ |
| บันทึกชำระ | กดครั้งเดียวลดยอดหนี้และบันทึกเป็นรายจ่าย/รายรับเต็มจำนวนในสมุดให้อัตโนมัติ พร้อมเก็บประวัติการชำระ |
| หมวดหมู่กำหนดเอง | มีให้ครบทั้งชุดใช้จ่ายส่วนตัวและร้านค้า เพิ่ม–ลบเองได้ |
| ค้นหาและกรอง | ค้นหาตามชื่อรายการหรือหมวดหมู่ กรองเฉพาะรายรับหรือรายจ่าย |
| นำเข้าจากข้อความ | วางข้อความหลายบรรทัดจากไลน์หรือโน้ต แล้วอ่านจำนวนเงิน วันที่ และเดาหมวดหมู่ให้อัตโนมัติ ตรวจแก้ได้ก่อนบันทึก |
| แชร์เข้าแอป | บน Android แชร์ข้อความจากไลน์มาที่แอปได้ตรง ๆ (Web Share Target) |
| ส่งออก CSV | เปิดต่อใน Excel หรือ Google Sheets ได้ (รองรับภาษาไทย) |
| สำรอง / นำเข้าข้อมูล | ไฟล์ JSON สำหรับย้ายข้อมูลข้ามเครื่อง |
| ใช้งานออฟไลน์ | Service worker แคชไฟล์ไว้ทั้งหมด เปิดใช้ได้แม้ไม่มีสัญญาณ |
| โหมดสว่าง / มืด | ปรับตามธีมของเครื่องอัตโนมัติ |
| อัปเดตอัตโนมัติ | แอปที่ติดตั้งไว้เช็กเวอร์ชันใหม่ให้เอง และแจ้งเตือนเมื่อมีของใหม่ |
| บอทไลน์ | จดผ่านแชทไลน์ได้ พิมพ์ "ค่าข้าว 120" หรือ **ส่งรูปสลิปโอนเงิน** แล้ว AI อ่านยอด/วันที่/ชื่อผู้รับให้ ถามหมวดก่อนบันทึก |
| ซิงค์ข้ามเครื่อง | เชื่อมกับ Google Sheet ของตัวเอง มือถือ/คอม/ไลน์ เห็นข้อมูลชุดเดียวกัน |

## เรื่องหนี้กับสมุดบัญชี

แอปนี้เป็นสมุด **เงินสด** — นับตอนเงินเคลื่อนจริง ไม่ใช่ตอนเกิดรายการ

- **กู้เงินมา / ขายเชื่อ** ยังไม่นับเป็นรายรับ แค่จดไว้ในหน้าหนี้
- **กดบันทึกชำระ** ถึงจะลงสมุด — จ่ายหนี้ลงเป็นรายจ่าย รับชำระลงเป็นรายรับ เต็มจำนวนที่เคลื่อนจริง
- เลือกลงเต็มจำนวน (ไม่ใช่เฉพาะดอกเบี้ยแบบบัญชีคู่) เพราะเงินออกจากกระเป๋าจริงเท่านั้น งบต่อหมวดกับกราฟจึงตรงกับเงินที่มีอยู่จริง

## การเก็บข้อมูล

ค่าเริ่มต้นคือเก็บใน `localStorage` ของเบราว์เซอร์บนเครื่องที่ใช้งาน **ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ไม่มีการติดตาม**

- การล้างข้อมูลเว็บไซต์ในเบราว์เซอร์จะลบรายการทั้งหมด ควรสำรองไฟล์ไว้เป็นระยะ
- โหมดไม่ระบุตัวตน (incognito) จะไม่เก็บข้อมูลหลังปิดหน้าต่าง

### ซิงค์ข้ามเครื่อง (ไม่บังคับ)

เปิดได้ที่ ⚙ → **ซิงค์ข้อมูล** โดยวางรหัสที่ได้จากบอทไลน์ (พิมพ์ "ซิงค์" ในแชท) ข้อมูลจะไปเก็บใน **Google Sheet ของคุณเอง** ไม่ใช่ของใครอื่น

- **รหัสซิงค์ไม่ได้ฝังอยู่ในโค้ดเว็บ** — ผู้ใช้วางเอง เก็บไว้ใน `localStorage` ของเครื่องนั้นเท่านั้น จึงไม่หลุดขึ้น GitHub
- ตัดสินข้อมูลชนกันด้วย last-write-wins ตาม `updatedAt` ของเครื่องที่แก้
- การลบใช้ tombstone (คอลัมน์ `deleted`) เครื่องอื่นจึงลบตามได้ และของที่ลบแล้วไม่ฟื้นกลับมา
- แอปรับได้เฉพาะที่อยู่ `script.google.com/macros/s/.../exec` เพื่อกันการถูกหลอกให้วางลิงก์ปลายทางของคนอื่น
- ปิดการซิงค์เมื่อไหร่ก็ได้ รายการที่มีอยู่แล้วในเครื่องยังอยู่ครบ

## ติดตั้งเป็นแอป

- **Android / Chrome** — เปิดลิงก์แล้วกดปุ่ม “ติดตั้งแอป” บนหน้าเว็บ หรือเมนู ⋮ → *ติดตั้งแอป*
- **iPhone / Safari** — ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*
- **คอมพิวเตอร์ / Chrome, Edge** — ไอคอนติดตั้งท้ายแถบที่อยู่ หรือปุ่ม “ติดตั้งแอป” บนหน้าเว็บ

## ปล่อยเวอร์ชันใหม่

แก้บรรทัดเดียวใน `sw.js`:

```js
const VERSION = "2026.08.27-2";   // เปลี่ยนเป็นค่าใหม่
```

แล้ว commit ไฟล์ที่แก้พร้อมกับ `sw.js` — เท่านี้พอ

เครื่องที่ติดตั้งแอปไว้จะได้เวอร์ชันใหม่แบบนี้:

- **เปิดแอปครั้งถัดไป** — ได้ของใหม่ทันทีโดยไม่ต้องทำอะไร
- **ถ้าเปิดแอปค้างไว้อยู่** — จะมีแถบ *"มีเวอร์ชันใหม่พร้อมใช้งาน"* ขึ้นด้านล่าง กด **อัปเดตเลย** แล้วหน้าจะโหลดใหม่ให้ กด **ภายหลัง** ก็ได้ เดี๋ยวเปิดรอบหน้าค่อยอัปเดตเอง

แอปจะเช็กเวอร์ชันใหม่ให้ตอนเปิด ตอนสลับกลับมาที่หน้าจอ ตอนเน็ตกลับมา และทุก 30 นาที เวอร์ชันที่กำลังใช้อยู่แสดงอยู่ท้ายหน้า

การอัปเดตไม่แตะข้อมูลใน `localStorage` รายการที่บันทึกไว้จึงอยู่ครบเสมอ

## รันบนเครื่องตัวเอง

Service worker ต้องใช้ `http://` หรือ `https://` (เปิดไฟล์ตรง ๆ ด้วย `file://` จะไม่ทำงาน)

```bash
git clone https://github.com/yuttachaicp-ops/money-book.git
cd money-book
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## โครงสร้างไฟล์

```
index.html              ทั้งแอปอยู่ในไฟล์เดียว (HTML + CSS + JS ไม่มี dependency)
manifest.webmanifest    ข้อมูลแอปสำหรับการติดตั้ง
sw.js                   service worker สำหรับใช้งานออฟไลน์
icons/                  ไอคอนแอป
```

ฟอนต์ดึงจาก Google Fonts (Anuphan, IBM Plex Sans Thai, IBM Plex Mono) และถูกแคชไว้หลังเปิดครั้งแรก นอกจากนี้ไม่มีการเรียกใช้ทรัพยากรภายนอกใด ๆ
